# Fictional family

Every person and document here is invented. Each person has one Markdown note;
parent, partner, source, place, and event objects live with the person whose
research they describe. Claims refer to that person's top-level source catalog
by stable ID. Kindred derives the graph records when it loads the archive. The
original register attachment remains a normal local file.

The archive covers adoption, shared ancestors, a partnership, Unicode,
approximate and conflicting dates, and disputed, tentative, and rejected
claims. Broken links and duplicate IDs are introduced in isolated automated
tests, keeping this demo usable.
