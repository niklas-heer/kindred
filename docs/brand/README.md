# Kindred logo

[Logo artwork](kindred-logo.png) is the horizontal mark used in the project README.
The interwoven branches suggest family connections; the evergreen lettering and
warm ivory field give it a calm, archival character. Keep the original aspect
ratio and leave the existing clear space around the mark. The opaque background
keeps its contrast consistent on light and dark pages.

Created on 2026-09-19 with the built-in image generation tool. This is a raster
PNG, not an editable vector master. The original generated file was copied into
this repository without image edits. Future app-icon or vector versions should
be reviewed at their intended display sizes.

## Generation prompt

```text
Use case: logo-brand.
Asset type: finished horizontal logo for the GitHub README of Kindred, an open-source local family-history application built around linked notes, human stories, and evidence.
Create one polished, original logo lockup on a flat warm ivory background. Wide 3:1 canvas, ideally 1536 by 512. A compact distinctive symbol at the left, and the word Kindred at the right, together optically centered with generous but not excessive margins.
The symbol should combine the idea of branching family connections and interwoven strands in a single simple, memorable silhouette, subtly suggesting a K. Rounded joins, deliberate negative space, a few connected forms; warm and human rather than a corporate network diagram. Pair it with beautifully spaced, highly legible, contemporary humanist serif lettering. All symbol and lettering in a rich dark evergreen color, high contrast against the ivory field.
Text exactly: "Kindred" (capital K, then lowercase i n d r e d). No tagline, no other lettering.
Crisp flat graphic design, professional editorial identity, balanced stroke weights, useful when displayed at 480 pixels wide. No gradients, shadows, mockup objects, paper texture, 3D, border, watermark, generic leafy tree, DNA helix, hearts, or stock family silhouettes. Deliver the actual logo artwork alone, not a presentation sheet or multiple concepts.
```
